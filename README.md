# ChatPro_1

一个 Python 聊天项目（开发中）。

## 环境要求

- Python 3.12+

## 快速开始

```bash
# 1. 创建并激活虚拟环境
python -m venv .venv
.\.venv\Scripts\activate

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行项目
python main.py
```

## 目录结构

```
ChatPro_1/
├── main.py            # 程序入口
├── requirements.txt   # Python 依赖
├── .gitignore         # Git 忽略规则
└── README.md          # 项目说明
```

## 关联 GitHub

在 GitHub 上创建同名仓库后执行：

```bash
git remote add origin https://github.com/<你的用户名>/ChatPro_1.git
git branch -M main
git push -u origin main
```
